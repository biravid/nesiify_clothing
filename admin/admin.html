GitHub & Netlify Deployment Workflow

  1. Place your product images into assets/products/ (e.g. NC009-1.jpg).
  2. In this manager: add new products, edit existing items, or delete outdated items.
  3. Enter filenames (e.g. NC009-1.jpg) — full paths are generated automatically.
  4. Click [ COPY COMPLETE JSON ] or [ DOWNLOAD JSON ].
  5. Replace data/products.json in your local project.
  6. Commit and push to GitHub — Netlify automatically deploys your live store!
